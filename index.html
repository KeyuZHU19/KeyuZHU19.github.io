RADAR: Closed-Loop Robotic Data Generation via Semantic Planning and Autonomous Causal Environment Reset

Yongzhong Wang*, Keyu Zhu*, Yong Zhong*, Liqiong Wang, Jinyu Yang, Feng Zheng

IROS 2026

* Equal contribution

PDF•arXiv

Abstract

RADAR is a fully autonomous closed-loop robotic data generation pipeline that combines semantic planning, in-context imitation learning, automated success evaluation, and causal environment reset to scale real-world robot data collection with minimal human intervention.
